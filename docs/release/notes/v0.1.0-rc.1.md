# Axrail 0.1.0-rc.1

First public release candidate for Axrail, an open-source governed execution harness for industrial and engineering AI agents.

## Highlights

- governed Tool execution with L0-L5 risk classification;
- immutable Tool invocation evidence shared across Policy, Approval, Audit and execution;
- Artifact / ChangeSet / Transaction execution model with optimistic concurrency and explicit rollback;
- approval quorum, evidence freshness, policy obligations, and conservative L4/L5 floors;
- provider-aware Tool, Validator and Policy isolation for multi-Adapter systems;
- explicit timeout and postcondition effect-uncertainty semantics;
- MCP bridge with descriptor refresh/reclassification and official MCP TypeScript SDK integration;
- model-agnostic AgentLoop plus OpenAI-compatible Responses provider;
- EventStore/session/correlation model with in-memory and embedded JSONL reference stores;
- vendor-neutral HMI Adapter Kit and reference HMI Agent flow;
- read-only diagnostic CLI;
- Node >=20 ESM-only public packages with TypeScript declarations.

## Release verification

The npm release candidate was validated on Node 20, 22 and 24 with:

- frozen dependency install;
- project-reference TypeScript build;
- 73 behavioral tests;
- emitted dependency-closure audit;
- 15 public package tarballs;
- clean runtime consumer imports;
- strict NodeNext TypeScript consumer compilation with `skipLibCheck: false`;
- Adapter SDK advanced-subpath imports;
- packaged CLI execution.

All 15 supported public packages were published as `0.1.0-rc.1` under the `rc` dist-tag with GitHub Actions provenance. The published artifacts correspond to source commit:

## Safety boundary

Axrail Policy/Approval is not a replacement for safety PLCs, deterministic interlocks, emergency stops, SIL/PL-rated functions, machine-controller safety logic, or regulated operating procedures.

For deployment, physical-action, safety-sensitive, regulated, or audit-dependent environments, applications should choose an explicit strict audit profile and a production-grade EventStore appropriate to their requirements.

## Package set

The release candidate contains 15 public packages under `@axrail/*`. `@axrail/core` remains private/experimental and is not part of the supported v0.1 public package set.
