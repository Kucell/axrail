# Axrail v0.1 Package Dependency and Smoke Graph

Status: **approved, implemented and verified for the prepared `0.1.0-rc.1` candidate**.

This document records the supported v0.1 package dependency topology used by the TypeScript project-reference build and clean-consumer package smoke tests.

`@axrail/core` is intentionally excluded because it is private/experimental for v0.1.

## Clean-consumer smoke matrix

`scripts/release/pack-smoke.mjs` verifies the packaged graph rather than only the workspace graph:

1. `pnpm pack` every supported package;
2. ensure exactly 15 `.tgz` artifacts exist;
3. create a clean temporary npm consumer;
4. install all 15 tarballs together;
5. dynamically import all 15 package roots;
6. execute the packaged `axrail --version` binary.

The tarballs include built `dist` output, package metadata and Apache-2.0 LICENSE text. Internal source paths are not public package entry points.

## Manual dry-run artifacts

`.github/workflows/release-dry-run.yml` can retain the same verified tarballs as a GitHub Actions artifact for 14 days. That workflow is no-publish and read-only with respect to repository contents.

## Build-order rule

Contributors should not hand-maintain a separate imperative build order. The project-reference graph is the source of truth for build dependencies, while this document describes the intended architecture topology and package-smoke boundary.
