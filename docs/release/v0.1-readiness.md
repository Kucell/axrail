## Production storage/audit guidance — DOCUMENTED

`JsonlEventStore` is an embedded/reference durable provider. It is not presented as a multi-process, fsync/rotation/retention/compliance-grade production audit database.

The default `best_effort` audit profile is a development/embedded usability default, not a production safety recommendation. Deployments that require durable evidence before engineering effects or commit boundaries should explicitly choose `required_before_effect` or `required_before_commit` and provide an EventStore appropriate to the application requirements.
