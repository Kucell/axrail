## Versioning and release automation — PARTIAL

`D-v01-versioning-release-policy` is approved.

Approved model:

- v0.1 public packages version in lockstep;
- candidate naming uses `0.1.0-rc.N` and `v0.1.0-rc.N` tags;
- final target is `0.1.0` / `v0.1.0`;
- serialized protocol versions remain independent from npm versions;
- root `CHANGELOG.md` is the human-readable release-note source of truth.

Issue #18 remains open because real publication automation is intentionally not enabled yet.

Remaining publication work includes:

- explicit/manual release workflow;
- artifact retention/upload;
- tag/GitHub Release automation;
- npm registry authentication through GitHub secrets/environments;
- provenance/signing/attestation where supported;
- final maintainer approval before publishing.

No npm package has been published by the current dry-run work.
