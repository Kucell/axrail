## Production storage/audit guidance — DOCUMENTED

`JsonlEventStore` is an embedded/reference durable provider, not a multi-process/compliance-grade production audit database. The default `best_effort` profile is a development/embedded default; applications needing durable pre-effect/pre-commit evidence should explicitly select a strict audit profile and a suitable EventStore.
