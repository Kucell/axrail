## Architecture gates — COMPLETE

- #19 governed-execution P1 review: **passed / closed**.
- #20 P2 follow-up: **resolved or explicitly scoped / closed**.
- #21 final pre-release architecture Gate: **focused re-review passed / closed**.
- `@axrail/harness` + `AdapterHost` is the supported v0.1 composition model.
- `@axrail/core` remains private/experimental/internal and is excluded from the supported public package set.

The final pre-release Gate verified:

- Transaction lifecycle observers cannot change already-committed outcome truth;
- side-effecting Tool timeout is classified as `execution_uncertain` and requests cooperative cancellation;
- Adapter Policy providers are Host-scoped and namespaced;
- multi-Adapter Transaction Policy evaluates every selected Adapter and aggregates conservatively;
- strict downstream TypeScript consumer compilation passes for packed declarations;
- emitted package dependency closure is audited.

## Versioning and release automation — PARTIAL

`D-v01-versioning-release-policy` is approved.

Approved model:

- v0.1 public packages version in lockstep;
- candidate naming uses `0.1.0-rc.N` and `v0.1.0-rc.N` tags;
- final target is `0.1.0` / `v0.1.0`;
- serialized protocol versions remain independent from npm versions;
- root `CHANGELOG.md` is the human-readable release-note source of truth.

Issue #18 remains open because real publication automation is intentionally not enabled yet.

Remaining publication work includes:

- tag/GitHub Release automation and policy;
- npm registry authentication through GitHub secrets/environments;
- provenance/signing/attestation where supported;
- immutable Action pinning before any credentialed release workflow;
- final maintainer approval before publishing;
- first real publication decision/action.

No npm package has been published by the current dry-run work.
